# Contributing

This is demo material from a single conference session, so it is not looking for
feature work. Two kinds of contribution are genuinely welcome:

- **Corrections.** If something here is factually wrong about Cosmos DB,
  PostgreSQL, `pgvector`, DiskANN, Apache AGE or Foundry, please say so. Being
  wrong in public is worse than being corrected.
- **Clarity.** If an explanation is confusing, that is a bug.

Open an issue before a pull request, so nobody spends an evening on something
that was never going to be merged.

## What will not be accepted

- Changes that make the demo more production-like. The warnings in the README are
  deliberate, and hiding them would make the sample more dangerous, not less.
- Additional cloud providers or databases. The session is about two Azure
  databases and the comparison between them.

## Conduct

Be decent. Disagree about the technology as much as you like, and not about the
person. Anything that would be unwelcome in a conference session is unwelcome
here.
